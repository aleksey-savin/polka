План утверждён 2026-08-10. Каждый этап завершается коммитом, обновлением этого файла и выполнением проверки этапа.

**Где мы сейчас (16 августа 2026).** MVP закрыт и работает на polka.saviny.ru; сверх плана сделаны эталонный каталог, циклы, списки, роли с модерацией, почта и тёмная тема. Приложение готово к тому, чтобы им пользовались не только семья и друзья: есть правила, жалобы, санкции и журнал действий. Регистрация остаётся по приглашению — это осознанный барьер.

## ИИ: функции по одной (каждая — отдельный этап)

Порядок обсуждается, каждая идёт со своим макетом. Общий закон: модель предлагает, применяет человек, у применённого стоит пометка «предложил ИИ» и кнопка «Откатить».

- Аннотация, когда её нет
- Тэги и жанры
- ~~Поиск в интернете по ISBN~~ — макет утверждается (M26)
- ~~Фото выходных данных (OCR)~~ — запланировано (M27)
- ~~Разбор нераспознанных~~ — сделано (M25)
- Парсинг и дозаполнение карточек
- Помощь с раскладыванием по полкам
- Описания подборок и советы
- Подсказки модератору

## Что дальше (не начато)

- **Ручная разметка циклов и подборок** — обещано вместе с расширенными списками; сейчас циклы приходят только из FantLab.
- **Контакт владельца в правилах** — на странице `/rules` стоит плейсхолдер; вписать до выхода за круг знакомых.
- **Открытая регистрация** — если решим расти; барьер приглашений снимается одним флагом, но тогда нагрузка на модерацию вырастет.
- **Массовое дозаполнение нераспознанных** с компьютера, распознавание обложки по фото.
- **Уведомления** о сроках возврата, экспорт и импорт каталога, полнотекстовый поиск (FTS5).

## Сквозная приёмка MVP

На проде, с телефона: регистрация → библиотека+полки → отсканировать стопку → разложить «Неразобранное» → оценка+рецензия → «дал почитать» → share-ссылка другу → заявка → одобрение → возврат. Патина/акценты, русский поиск, рестарт без потерь.

## Риски (кратко)

TanStack Start в RC и близкий better-auth 1.7 → точная пиновка; покрытие русских ISBN 40–70% → ручная форма первоклассна; FantLab «test mode» → best-effort с кэшем; сканер при плохом свете → ранний тест M4, fallback — ввод цифр; WAL-бэкап → копировать весь /data.
