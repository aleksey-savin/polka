## Проверки этапов

- **M0** ✔ Владелец прочитал документы и согласен.
- **M1** ✔ Владелец апрувит макеты ключевых экранов.
- **M2** ✔ Пуш в main → сайт обновился по HTTPS; рестарт контейнера сохраняет БД и сессии; `REGISTRATION_OPEN=false` прячет форму и режет API.
- **M3** ✔ 20 реальных книг; поиск «стругацкие» находит «Стругацкие»; серия из 3 томов по порядку; патина работает, ручной розовый перекрывает; обложки живут после рестарта.
- **M4** ✔ С реального телефона (Android Chrome + iOS Safari) по HTTPS отсканировать 5 книг из завала: ≥3 автозаполнились; «не нашлось» → ручная форма с ISBN; `bun test` зелёный.
- **M5** ✔ Выдал → штамп и строка в /loans; повторная выдача блокируется; вернул → история; подаренное ушло с полки, находится фильтром.
- **M6** ✔ Инкогнито с телефона: смотрю витрину, прошу книгу; владелец конвертит заявку в выдачу; отозванный токен → 404; приватных полей нет в HTML.
- **M7** ✔ Add to Home Screen (Android+iOS); чистый клон `bun install && bun run dev` работает; `compose up` с нуля → демо-библиотека.

## Сквозная приёмка MVP

На проде, с телефона: регистрация → библиотека+полки → отсканировать стопку → разложить «Неразобранное» → оценка+рецензия → «дал почитать» → share-ссылка другу → заявка → одобрение → возврат. Патина/акценты, русский поиск, рестарт без потерь.

## Риски (кратко)

TanStack Start в RC и близкий better-auth 1.7 → точная пиновка; покрытие русских ISBN 40–70% → ручная форма первоклассна; FantLab «test mode» → best-effort с кэшем; сканер при плохом свете → ранний тест M4, fallback — ввод цифр; WAL-бэкап → копировать весь /data.
