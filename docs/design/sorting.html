Примечания макета

· Первый тап по чекбоксу включает режим выбора; дальше вся карточка — одна большая цель. Переход на книгу в режиме выбора выключен.

· Панель: счётчик «N кн.», широкая кнопка, круглый «✕» — ничего не переносится даже на узком экране.

· Шторка знает контекст: выбраны книги из «Офиса» — предлагает «Офис», а не первую библиотеку по списку. Полки — списком, тап выбирает. Все диалоги приложения на мобильном станут такими шторками.

· После «Переместить»: остались книги в списке — остаёмся разбирать; список опустел — переходим на целевую полку.
