# Polka — UX/UI гайдлайн

> Статус: **каркас**. Наполняется на этапе M1 (дизайн) и становится источником истины для реализации UI. Утверждённое направление зафиксировано ниже и не меняется без решения владельца.

## Направление (утверждено)

**Не ретро.** База — «современная библиотека»: светло, чисто, уютно; настроение новых городских библиотек (светлое дерево, воздух, мягкие тени). Mobile-first: главный сценарий — телефон в руке у книжной полки.

**Фишка-подпись — «живые полки»:**
- **Авто-патина.** Цвет полки вычисляется из медианного года изданий стоящих на ней книг: старые книги → тёплая, «пожелтевшая» полка; новые → свежая белая, «будто только покрашена». Интерполяция в OKLCH; книги без года не участвуют; полка без данных — нейтральная. Рядом легенда: «медианный год изданий — N».
- **Ручной акцент.** Полке можно задать свой цвет (пресеты + произвольный); он перекрывает патину. Пример: полка «романтика» — розовая.

**Лёгкие библиотечные отсылки допустимы** (утверждено пользователем): точечные метафоры — штамп-бейдж статуса («НА РУКАХ», «ПОДАРЕНО»), корешки книг на полках. Без винтажной стилизации всего интерфейса.

**Запреты:** шаблонные AI-дефолты (кремовый фон + терракотовый акцент + контрастный сериф; тёмный фон + кислотный акцент; «газетная» вёрстка) — направление должно быть собственным.

## Язык интерфейса

Русский. Тон — спокойный, разговорный, без канцелярита; действия называются глаголами результата: «Дать почитать», «Вернули», «Добавить ещё» (не «Отправить»/«Submit»). Название действия неизменно по всему потоку: кнопка «Опубликовать» → тост «Опубликовано». Ошибки говорят, что случилось и что делать, без извинений и тумана. Пустой экран — приглашение к действию.

## Токены (заполняется в M1)

- **Палитра**: 4–6 именованных oklch-значений → маппинг на семантические переменные shadcn (`--background`, `--foreground`, `--card`, `--primary`, `--border`, `--ring`, `--radius`…). Светлая тема; структура токенов должна позволить добавить тёмную позже.
- **Патина**: конечные точки интерполяции (цвет «старой» и «новой» полки), формула/шкала лет. TBD в M1.
- **Пресеты акцентов полок**: набор из ~8 цветов + произвольный. TBD в M1.
- **Типографика**: пара шрифтов с **полноценной кириллицей** (дисплейный + текстовый/UI), шкала размеров, начертания. TBD в M1.
- **Сетка и отступы**: TBD в M1.

## Ключевые экраны (макеты — этап M1)

1. Вход / регистрация
2. Библиотека: полки с корешками + патина/акценты, «Неразобранное»
3. Полка
4. Карточка книги (+ статусы, выдачи, оценка/рецензия)
5. Добавление: сканер / ISBN / вручную, черновик, «Добавить ещё»
6. Публичная share-витрина + заявка «Хочу взять почитать»
7. «На руках» (/loans)

## Качество (пол, не потолок)

Адаптивность до 360px; видимый фокус с клавиатуры; `prefers-reduced-motion` уважается; тап-таргеты ≥ 44px; контраст текста ≥ WCAG AA.
